https://weatherfit.com. example2.webp Weather Fit — iOS app (4.6★, 16K+ ratings) that recommends daily outfits based on forecast. 
    Core concept: a customizable character (skin tone, hair, glasses, etc.) is dressed each day to match the weather — shorts when warm, puffer jacket when cold, umbrella before rain, sunglasses on sunny days.
    Wardrobe-aware: users add clothes they actually own by category (tops, bottoms, outerwear, footwear, accessories); app only suggests items from that wardrobe and adapts to a set "comfort level" (runs warm/cool).
    Data source: powered by Apple Weather — current, 10-day forecast, minute-by-minute precipitation, UV index, wind, humidity, air quality, alerts.
    Multi-location: unlimited saved locations, each with its own landscape (city/mountains/beach/suburb) and time-of-day sky.
    Surfaces: home/lock screen widgets, Apple Watch app with complication, and two daily push reports (morning/evening) plus quiet umbrella & sunscreen reminders.
    Monetization: free to download; some features (e.g., widget) gated behind subscription per a user review.
    Relevant to your Weather2 project brief: it validates the "character + outfit + weather" concept and reminder pattern (umbrella/sunscreen), which closely mirrors your project requirements.
